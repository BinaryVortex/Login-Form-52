# Login Form

Login Form Built Using HTML, CSS and JavaScript.

![Login Form Screenshot](./Screenshot%202024-07-27%20132646.png)

## Overview

A clean, responsive login form built with semantic HTML, modern CSS, and a small amount of JavaScript for basic client-side validation and interactivity. This is a small front-end project intended as a UI component or a learning exercise.

## Files

- index.html — main HTML file containing the login form markup
- style.css — styles for the form and layout
- Screenshot 2024-07-27 132646.png — demo screenshot of the form
- view-futuristic-city-with-greenery-vegetation.jpg — background/hero asset used in the project

## Demo / Screenshot

The screenshot above shows the login form as it appears in desktop view. Open `index.html` in a browser to see the live form.

## Features

- Simple, modern design
- Responsive layout for different screen sizes
- Basic client-side validation (required fields)
- Easily customizable styles

## How to run

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-52.git
2. Open the `index.html` file in your preferred browser (double-click or `File -> Open`).

Alternatively, serve the folder with a simple HTTP server (recommended for testing local assets):

- Python 3.x:

  python -m http.server 8000

Then visit http://localhost:8000 in your browser.

## Customize

- Edit `style.css` to change colors, spacing, and layout.
- Modify `index.html` to add/remove fields or change form behavior.
- Replace the images in the repository with your own assets (keep the same filenames or update the references in `index.html`).
